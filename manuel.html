Manuel d'utilisation d'AlgoCraft

Écrire, exécuter, comprendre et traduire des algorithmes en pseudo-code français — tout ce qu'il faut savoir, section par section.

1Présentation

AlgoCraft est un éditeur pédagogique d'algorithmes. On y écrit des algorithmes en pseudo-code français (« Algorithme… Variables… Debut… Fin »), comme en cours, puis on peut :

  • les exécuter immédiatement, avec saisie des valeurs dans la console ;
  • les suivre pas à pas en observant l'évolution de chaque variable ;
  • les vérifier : les erreurs sont soulignées pendant la frappe, avec une explication et un exemple de correction ;
  • les traduire automatiquement en Python, C, C++, C#, Java ou JavaScript ;
  • les représenter sous forme d'algorigramme (organigramme) exportable en image ;
  • visualiser les tableaux case par case pendant l'exécution ;
  • les partager (code ou traduction) par WhatsApp, Telegram, e-mail ou fichier.

Le logiciel s'adresse aux élèves et étudiants qui apprennent l'algorithmique, et aux enseignants qui veulent illustrer leurs cours.

Installer

  1. Téléchargez l'archive depuis le site d'AlgoCraft (menu Aide › Télécharger la dernière version).
  2. Décompressez-la dans un dossier de votre choix (par exemple Documents\AlgoCraft).
  3. Lancez AlgoCraft version 2.0.exe. Au premier lancement, l'extension .agc est associée à AlgoCraft : un double-clic sur un fichier .agc l'ouvrira directement.

Premier démarrage

Après l'écran de chargement, AlgoCraft affiche la page d'accueil : créer un fichier ou un projet, ouvrir un fichier, reprendre un fichier récent, ouvrir le mémo du langage, ce manuel ou un exemple. Échap ou la croix la ferme et montre l'algorithme d'accueil (une fonction et une procédure) : appuyez sur F5 pour l'exécuter. La page revient par Fichier › Page d'accueil ; décochez « Afficher cette page au démarrage » pour ne plus la voir.

Aux démarrages suivants, AlgoCraft rouvre les fichiers qui étaient ouverts lors de la dernière fermeture, ainsi que le fichier actif.

Récupération. Toutes les 30 secondes, AlgoCraft garde une copie des fichiers modifiés et pas encore enregistrés. Si l'ordinateur s'éteint ou si AlgoCraft se ferme brutalement, il propose au démarrage suivant de rouvrir ces fichiers tels qu'ils étaient. Après une fermeture normale, les copies sont effacées.

Mises à jour. Au démarrage (au plus une fois par jour), AlgoCraft regarde si une nouvelle version est publiée. Si c'est le cas, « ⬆ Version … disponible » apparaît dans la barre d'état : un clic montre les nouveautés et propose Installer maintenant (téléchargement de l'installateur, fermeture d'AlgoCraft après proposition d'enregistrer, puis installation), Plus tard ou Ignorer cette version. Vérification à la demande : Aide › Rechercher des mises à jour…

Barre latérale

Projet

Les fichiers ouverts. Cliquez pour passer de l'un à l'autre ; un point ● signale un fichier modifié non enregistré. Boutons : nouveau fichier, ouvrir.

Structure

Le plan de l'algorithme : son nom, chaque fonction et procédure (avec ses paramètres) et le programme principal. Un clic place le curseur sur la ligne correspondante.

Insertion rapide

Des boutons classés par couleur (instructions, boucles, routines, fonctions mathématiques) qui insèrent un modèle prêt à compléter à l'emplacement du curseur.

Panneau du bas

  • Console : affichage des résultats (Ecrire) et saisie des valeurs (Lire). Le bouton Effacer vide la console.
  • Problèmes : liste des erreurs et avertissements ; un clic va à la ligne concernée. Le nombre de problèmes apparaît en pastille sur l'onglet.

Barre d'état

En bas de la fenêtre : l'état (prêt, exécution en cours, saisie attendue…), le nombre d'erreurs et d'avertissements (cliquable), la position du curseur (ligne, colonne), la langue des mots-clés, le zoom et l'encodage.

5L'éditeur de code

L'éditeur colore le code (mots-clés, types, textes, nombres, commentaires, fonctions), numérote les lignes, met en évidence la ligne courante et les parenthèses associées, affiche des guides d'indentation et permet de plier les blocs (le petit « − » dans la marge).

  • Indentation automatique : après Alors, Faire, Debut… la ligne suivante est décalée ; en tapant FinSi, FinPour… la ligne revient à l'alignement du bloc.
  • Fermetures automatiques : guillemets et parenthèses.
  • Info-bulles : survolez une variable, une fonction ou une procédure pour voir sa déclaration.

Autocomplétion

Dès les premières lettres, une liste de propositions s'ouvre ; Ctrl+Espace l'ouvre à tout moment. Chaque proposition porte une pastille de couleur qui indique sa nature :

PastilleNatureCe qui est inséré
Mot-clé / modèleSi, Pour, TantQue…Le bloc complet (par exemple Si … Alors / FinSi), curseur placé au bon endroit.
Variable, paramètre, constanteLes noms déclarés dans l'algorithmeEn début de ligne : x <- prêt pour l'affectation.
Fonction, procédureVos routines et les fonctions intégréesNom() avec le curseur entre les parenthèses, puis la signature s'affiche.
Type, champentier, reel… ; champs après p.Le nom.

La liste s'adapte au contexte : en début de ligne elle propose d'abord la fermeture du bloc ouvert (FinPour…), puis les instructions ; dans une condition, Alors / Faire passent en tête ; après : seuls les types sont proposés ; après un point, les champs de la structure. Une description de chaque proposition s'affiche au-dessus de la ligne. Validez avec Entrée ou Tab, fermez avec Échap.

Vérification en direct

Pendant la frappe, AlgoCraft analyse le code : les erreurs sont soulignées en rouge, les avertissements en orange, et le message s'affiche sous la ligne (option Affichage › Messages d'erreur sous les lignes). Chaque message explique le problème et propose en général un exemple correct.

// ligne 12 : « Ecrir » n'est pas une instruction connue.
//            Vouliez-vous dire « Ecrire » ?  Exemple : Ecrire("Bonjour")

F7 lance une vérification complète sans exécuter.

Corrections automatiques

Beaucoup d'erreurs se corrigent en un geste. Le message sous la ligne se termine alors par [Ctrl+. : corriger] et, dans l'onglet Problèmes, une ligne Corriger : … est cliquable. Ctrl+. ouvre la liste des corrections de la ligne (ou va au prochain problème qui en a). Chaque correction s'annule avec Ctrl+Z.

ErreurCorrection proposée

Bloc resté ouvert : Fin arrive avant FinSi, FinPour…Ajouter la fermeture manquante juste avant, à la bonne indentation
Mot de fermeture en trop (FinPour sans Pour)Supprimer la ligne
x = 3 pour affecterRemplacer « = » par « <- »

6Le langage algorithmique

Bon à savoir Majuscules et accents ne comptent pas : Ecrire, écrire et ECRIRE sont identiques. Les commentaires commencent par //. Le menu Aide › Mémo du langage ouvre un algorithme récapitulatif exécutable.

Structure d'un algorithme

Algorithme NomDeLAlgorithme

Constantes
    N = 10

Variables
    a, b : entier
    moyenne : reel

Debut
    // instructions du programme principal
Fin

// fonctions et procédures : avant ou après le programme principal

Types et déclarations

TypeValeursExemple
entiernombres entiersage : entier
reelnombres à virgule (on écrit 3.5)prix : reel
chainetexte entre guillemetsnom : chaine
caractereun seul caractèrec : caractere
booleenVrai ou Fauxtrouve : booleen
tableau[n] de Tn cases de type T (indices 0 à n−1)notes : tableau[30] de reel

Plusieurs variables du même type se déclarent ensemble : i, j, k : entier. Une variable doit être déclarée avant d'être utilisée.

Instructions de base

InstructionRôle
x <- 5Affectation (on peut aussi écrire ← ou :=).
Ecrire("Total : ", t)Affiche les éléments à la suite (aussi Afficher).
Lire(x)Demande une valeur dans la console ; la saisie est contrôlée selon le type de x.
Retourne valeurDans une fonction : renvoie le résultat.
NomProcedure(a, b)Appel d'une procédure.

Conditions

Si note >= 10 Alors
    Ecrire("Admis")
SinonSi note >= 8 Alors
    Ecrire("Rattrapage")
Sinon
    Ecrire("Ajourné")
FinSi

Boucles

Pour i allant de 1 à 10 Faire            // « pas -1 » pour compter à rebours
    Ecrire(i)
FinPour

TantQue x > 0 Faire                     // testée avant chaque tour
    x <- x div 2
FinTantQue

Repeter                                // au moins un tour
    Lire(n)
Jusqu'à n > 0

Une boucle qui ne s'arrête pas est interrompue par le bouton Arrêter (Maj+F5) ou au bout de la durée maximale réglée dans les préférences.

Tableaux

Variables
    t : tableau[5] de entier          // t[0] … t[4]
    m : tableau[3][4] de reel        // deux dimensions
Debut
    Pour i allant de 0 à 4 Faire
        t[i] <- i * i
    FinPour
    m[1][2] <- 3.5
Fin

Un indice hors des limites provoque une erreur claire (« les indices vont de 0 à 4 »).

Structures (enregistrements)

Structure Point
    x, y : reel
FinStructure

Variables
    p : Point
Debut
    p.x <- 2
    p.y <- 5
    Ecrire("(", p.x, ", ", p.y, ")")
Fin

Fonctions et procédures

Fonction Carre(x : entier) : entier
Debut
    Retourne x * x
FinFonction

Procedure Echanger(var a : entier, var b : entier)
Variables
    tmp : entier
Debut
    tmp <- a
    a <- b
    b <- tmp
FinProcedure
  • Une fonction renvoie une valeur avec Retourne et s'utilise dans une expression : y <- Carre(4).
  • Une procédure ne renvoie rien et s'appelle comme une instruction : Echanger(x, y).
  • Par défaut, les paramètres sont passés par valeur (copie). Avec var (ou E/S, ref), le paramètre est passé par référence : la routine modifie la variable de l'appelant.
  • La récursivité est autorisée (exemple « Factorielle »).

Mots-clés anglais

Les mots-clés anglais sont acceptés : Algorithm, Begin, End, Print, Read, If … Then … Else … EndIf, For i from 1 to 10 Do … EndFor, While … Do … EndWhile, Repeat … Until, Function … EndFunction, Procedure … EndProcedure, Return, integer, real, string, boolean, array[n] of T. La commande Édition › Mots-clés en anglais convertit automatiquement tout le code (vos noms de variables, les textes et les commentaires ne changent pas).

7Exécuter un algorithme

Appuyez sur F5 ou cliquez sur Exécuter. L'algorithme est d'abord vérifié ; s'il contient une erreur, elle est signalée et le curseur se place sur la ligne fautive. Sinon il s'exécute dans un fil séparé : l'interface reste utilisable et Arrêter l'interrompt à tout moment.

Console et saisies

Quand l'algorithme rencontre Lire(x), la console affiche « Valeur de x : » et attend votre saisie ; validez avec Entrée. Une saisie incompatible avec le type (du texte pour un entier, par exemple) est refusée avec une explication, et la question est reposée. Les flèches ↑ ↓ rappellent les saisies précédentes.

Points d'arrêt

Cliquez dans la marge, à gauche des numéros de ligne (ou appuyez sur F9) : un rond rouge marque un point d'arrêt. Lancez ensuite l'exécution avec F5 : elle s'arrête avant chaque ligne marquée, la ligne est surlignée et l'onglet Variables montre la valeur actuelle de chaque variable (en couleur : ce qui a changé depuis la pause précédente).

  • F5 (le bouton devient Continuer) : reprendre jusqu'au prochain point d'arrêt ;
  • F10 (le bouton devient Ligne suivante) : exécuter la ligne et s'arrêter sur la suivante ;
  • Maj+F5 : arrêter l'exécution.

Dans une boucle, l'exécution s'arrête à chaque tour. Les points d'arrêt suivent leurs lignes quand vous modifiez le code ; chaque fichier garde les siens. Ctrl+Maj+F9 (ou un clic sur « ● n point(s) d'arrêt » dans la barre d'état) les supprime tous.

Exécution pas à pas et tableau de suivi

F10 ouvre la fenêtre d'exécution pas à pas : la ligne en cours est surlignée, l'inspecteur montre la valeur de chaque variable avant la ligne. Avancez d'une ligne avec F10 ; F5 continue jusqu'au prochain point d'arrêt de l'éditeur (ou jusqu'à la fin).

L'onglet Tableau de suivi construit automatiquement le tableau que l'on fait au tableau en classe : une ligne par instruction exécutée (numéro, ligne du code, instruction) et une colonne par variable, avec sa valeur juste après l'instruction. Les valeurs qui viennent de changer sont en couleur et en gras. Un double-clic sur une ligne la surligne dans le code. Copier le met dans le presse-papiers (à coller dans Excel ou Word) ; Exporter CSV… l'enregistre en fichier ouvrable dans Excel. Le tableau s'arrête à 5 000 instructions.

Pour revoir une exécution en avant et en arrière, utilisez la visualisation.

Onglet Problèmes

Les erreurs (rouge) et avertissements (orange) de l'analyse et de l'exécution y sont listés avec leur ligne et leur colonne. Un clic place le curseur sur la ligne. Avertissements typiques : résultat d'une fonction appelé sans être utilisé, compteur de boucle non déclaré, boucle Pour qui devrait sans doute avoir un « pas -1 ».

Onglet Variables

À la fin d'une exécution, l'onglet Variables présente toutes les variables du programme principal avec leur type et leur valeur finale (tableaux et structures compris). Pendant une pause sur un point d'arrêt, il montre les valeurs actuelles. Double-cliquez sur une ligne pour copier sa valeur.

8Traduction vers d'autres langages

Le panneau de droite affiche en permanence la traduction de l'algorithme dans le langage choisi : Python, C, C++, C#, Java ou JavaScript. Elle se met à jour pendant que vous écrivez. Le code produit est complet et compilable : déclarations, lectures au clavier, tableaux, structures, fonctions et procédures (les paramètres passés par référence sont traduits selon les possibilités de chaque langage, avec un commentaire explicatif).

  • Changez de langage avec les boutons du panneau ou la liste de la barre d'outils.
  • Traduction › Ouvrir dans une fenêtre affiche le code dans une fenêtre séparée, avec copie et enregistrement.
  • Traduction › Enregistrer le code traduit crée directement le fichier .py, .c, .cpp, .cs, .java ou .js.
  • Le panneau se masque avec Ctrl+T.
Traduction du pseudo-code Pour passer les mots-clés de l'algorithme lui-même du français à l'anglais (ou l'inverse), utilisez Édition › Mots-clés en anglais / en français.

9Algorigramme

Outils › Algorigramme dessine l'organigramme normalisé de l'algorithme :

FormeSignification
Rectangle à bouts arrondisDébut / fin
RectangleTraitement (affectation)
ParallélogrammeLecture / écriture
LosangeCondition (Si, TantQue, Jusqu'à) avec ses sorties Oui / Non
HexagoneBoucle Pour (préparation)
Rectangle à doubles bordsAppel de procédure

Les branches d'un Si sont placées côte à côte et se rejoignent ; les boucles ont leur flèche de retour. La liste en haut à gauche permet d'afficher le diagramme du programme principal ou de chaque fonction / procédure.

  • Zoom : boutons − / +, Ctrl+molette, Ctrl+0 pour ajuster à la fenêtre.
  • Déplacement : glisser avec la souris, molette (vertical), Maj+molette (horizontal), flèches du clavier.
  • Export : PNG (image haute résolution), SVG (vectoriel, idéal pour un rapport), ou copie dans le presse-papiers (Ctrl+C).
  • Actualiser (F5) reconstruit le diagramme après une modification du code.

Les couleurs suivent le thème choisi (clair, sombre, nuit bleue).

10Visualisation des tableaux

Outils › Visualisation des tableaux exécute l'algorithme en enregistrant chaque étape, puis vous laisse rejouer l'exécution comme une vidéo :

  • les tableaux (1, 2 ou 3 dimensions, de tout type) sont dessinés case par case avec leurs indices ; les cases qui viennent de changer sont mises en couleur ;
  • la ligne de code exécutée s'affiche au-dessus ;
  • à droite : les variables (celles qui changent sont en gras) et la console jusqu'à cette étape ;
  • en bas : lecture / pause (Espace), étape précédente / suivante (← →), début / fin (Début Fin), vitesse de 0,25× à 10×, et un curseur pour aller directement à n'importe quelle étape.

Si l'algorithme lit des valeurs, tapez-les à l'avance dans la zone Entrées (séparées par des espaces ou des points-virgules) ; s'il en manque, elles sont demandées pendant l'enregistrement. Cliquez sur Exécuter et enregistrer (F5) pour recommencer avec d'autres valeurs.

Idéal pour les tris Ouvrez l'exemple « Tri à bulles » puis la visualisation : chaque échange de cases apparaît en couleur.

11Partager le code

Outils › Partager le code se fait en trois étapes :

  1. Que partager ? — le code actuel, un fichier .agc, le code traduit (Python, C, C++, C#, Java, JavaScript, ou le pseudo-code avec mots-clés anglais / français) ou un fichier traduit déjà enregistré (.py, .c, .cpp, .cs, .java, .js).
  2. Aperçu — le contenu exact qui sera envoyé, coloré, avec son nombre de lignes ; un message d'accompagnement peut être ajouté.
  3. Envoyer avec — WhatsApp, Telegram, Gmail, votre messagerie (e-mail), copie dans le presse-papiers, ou enregistrement d'une copie dans un fichier.
Code long Les liens de partage ont une longueur limitée. Pour un long code, AlgoCraft le copie automatiquement : il suffit de le coller (Ctrl+V) dans la conversation ou le message qui s'ouvre.

13Thèmes, langue et préférences

  • Thème (Affichage › Thème ou le bouton de la barre d'outils) : Clair, Sombre, Nuit bleue. Toutes les fenêtres, l'éditeur, la traduction et l'algorigramme suivent le thème.
  • Langue de l'interface (Langue, ou le bouton FR/EN) : français ou anglais. Les messages et la console suivent la langue choisie.
  • Taille du texte : Ctrl+molette, Ctrl++ / Ctrl+−, Ctrl+0.
  • Vérifier pendant la frappe et Messages d'erreur sous les lignes : dans le menu Affichage.
  • Mode présentation (F11, Affichage › Mode présentation) : plein écran, barre latérale et traduction masquées, texte du code et de la console agrandi, pour projeter en classe. F11 ou Échap pour revenir.

Ces réglages, la taille de la fenêtre, les panneaux affichés, les fichiers récents et les fichiers ouverts sont conservés d'une session à l'autre dans %APPDATA%\AlgoCraft\preferences.json. Supprimer ce fichier rétablit les réglages par défaut.

15Questions fréquentes

« Variable non déclarée » alors qu'elle l'est

Vérifiez l'orthographe et que la déclaration se trouve bien dans la section Variables du bon bloc : une variable déclarée dans une fonction n'existe pas dans le programme principal.

Mon programme ne s'arrête pas

Une boucle TantQue dont la condition reste vraie tourne indéfiniment. Cliquez sur Arrêter (Maj+F5), puis utilisez le pas à pas pour voir pourquoi la condition ne change pas.

Ma procédure ne modifie pas ma variable

Le paramètre est passé par valeur. Ajoutez var devant le paramètre : Procedure Doubler(var x : entier).

« Indice hors limites »

Les indices commencent à 0 : un tableau tableau[10] va de t[0] à t[9]. Une boucle Pour i allant de 1 à 10 déborde au dernier tour.

Le code traduit ne compile pas

Vérifiez d'abord que l'algorithme s'exécute sans erreur dans AlgoCraft. Si le problème persiste, signalez-le avec le code concerné via Aide › Nous contacter.

Les suggestions enregistrées ne s'affichent pas

Elles proviennent de la base LocalDB. Si SQL Server LocalDB n'est pas installé, AlgoCraft fonctionne normalement avec les suggestions intégrées.

Où sont mes réglages ?

Dans %APPDATA%\AlgoCraft\preferences.json. Le journal des erreurs est %LOCALAPPDATA%\AlgoCraft\algocraft.log.
